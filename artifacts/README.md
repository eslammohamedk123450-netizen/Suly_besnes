- الإصدار: `1.6` (رقم البناء `7`)
- الحجم: نحو 10.3 MB

**تنبيه حفظ مهم:** ربط الحساب السحابي ومزامنته لا ينقلان عالم الضيف كاملًا في النسخة الحالية. إذا كان لديك تقدم مهم محفوظ كضيف، فلا تحذف إصدار 1.5 قبل توفر نسخة احتياطية أو مسار نقل مؤكد؛ حذف التطبيق قد يمحو هذا التقدم. مفتاح توقيع 1.5 القديم غير متاح في بيئة البناء الحالية لإنشاء تحديث متوافق فوقه.
