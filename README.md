# إمبراطورية الأعمال | Business Empire

لعبة محاكاة اقتصادية عربية فردية، مبنية بـ React وTypeScript وCSS مع واجهة RTL. تبدأ بمصر ورصيد 1,000,000 جنيه مصري. الحلقة القابلة للعب تربط المزادات ومنافسة الشخصيات الآلية وملكية الأراضي وتأسيس تسعة قطاعات وشراء المواد الخام والإنتاج وبيع المنتجات والاستثمار والأحداث اليومية والتقارير والمهام. كل الأسعار والعوائد والأحداث محاكاة داخل اللعبة، وليست بيانات سوق أو منتجات مالية حقيقية.

مستودع GitHub المصدر: https://github.com/eslammohamedk123450-netizen/Suly_besnes

اللعب الفردي متاح كضيف دون تسجيل دخول أو مدفوعات؛ يحفظ الضيف عالمه محليًا على الجهاز. يمكن إنشاء حساب اختياري لمزامنة الحفظ مع Supabase واستعادته على جهاز آخر، كما يمكن ربط عالم الضيف بحساب من الإعدادات. يحتاج تسجيل الحساب ومزامنته إلى اتصال بالإنترنت، أما اللعب والحفظ المحلي فيعملان دون اتصال. تُرحّل ملفات الحفظ السابقة إلى المخطط الجديد دون حذف تقدم اللاعب. تشمل الحلقة أيضًا تداول ذهب بسعر محاكاة ثابت والتزامات مالية تُعرض بوضوح عند العجز.

## التشغيل

يتطلب المشروع Node.js وpnpm. من مجلد المشروع شغّل:

```bash
pnpm install
pnpm dev
```

يبني `pnpm dev` نسخة الإنتاج المضغوطة ثم يعرضها على المنفذ 3000؛ وهو مسار معاينة أخف من خادم التطوير. لتطوير المصدر مع إعادة التحميل الفوري استخدم `pnpm dev:hmr`.

لفحص الأنواع وإنشاء نسخة الإنتاج:

```bash
pnpm typecheck
pnpm build
```

## البداية والحفظ والعمل دون اتصال

عند أول فتح، اختر اللعب كضيف أو سجّل الدخول/أنشئ حسابًا. بعد ذلك اختر الدولة المتاحة واكتب اسم المستثمر ثم أنشئ عالمك. مصر هي الدولة المضافة حاليًا، ويبدأ اللاعب برصيد مليون جنيه مصري. يستعيد التطبيق ملف اللاعب تلقائيًا عند الزيارة التالية، ويُحفظ عالم الضيف تحت معرّف محلي ثابت. يقوم مخطط الحفظ v4 بترحيل ملفات v1 وv2 وv3، ويربط الأراضي بالشركات القديمة، ويملأ تكاليف التشغيل والطاقة الافتراضية، ويعيد تسوية مجاميع دفتر الحساب قدر الإمكان.

بعد أول زيارة متصلة، يسجل إصدار الإنتاج عامل خدمة ويحفظ ملفات الواجهة والصورة المحلية في ذاكرة الجهاز، لتستطيع إعادة فتح اللعبة دون اتصال. تُستخدم صورة القاهرة محليًا في `public/images`; مصدرها صفحة Unsplash العامة: https://unsplash.com/photos/city-skyline-with-river-and-boats-under-hazy-sky-Z1tl3nb_c4E . راجع https://unsplash.com/license .

## الإشعارات وأكواد المكافآت

تظهر إشعارات نجاح أو رفض المعاملات أعلى الشاشة. يبدأ مظهرها داكنًا، ويمكن تبديله إلى مظهر فاتح من الإعدادات، ويُحفظ الاختيار على الجهاز. تتضمن الإعدادات أيضًا اعتماد «تطوير شركة Suly- Technologies».

لم يُنفذ استرداد الأكواد بعد. يشرح [تصميم أكواد المكافآت دون اتصال](docs/offline-redeem-codes.md) طريقة القسائم الموقعة وحدود منع إعادة استخدام الكود نفسه على أجهزة منفصلة دون اتصال.

## التغليف إلى Android لاحقًا

أُبقي إعداد Capacitor والحزم وسكربتات Android جاهزة كمسار لاحق؛ لم يُنشأ مجلد Android ولم يُبنَ APK الآن، بناءً على طلب المستخدم إكمال اللعبة أولًا. بعد اكتمال اللعبة وطلب التغليف، جهّز منصة Android مرة واحدة عبر:

```bash
pnpm cap:add:android
```

ثم يمكن مزامنة ملفات الويب وإنشاء APK debug قابل للتثبيت عبر:

```bash
pnpm cap:sync
pnpm cap:apk:debug
```

يتطلب ذلك Android SDK وبيئة بناء مناسبة. APK debug للتثبيت التجريبي، وليس إصدارًا موقّعًا للنشر في Play Store.
