# إمبراطورية الأعمال | Business Empire

نسخة أولية عربية من لعبة محاكاة أعمال فردية. واجهتها مبنية بـ React وTypeScript وCSS، واتجاهها RTL. لا تحتاج إلى خادم أو تسجيل دخول أو قاعدة بيانات.

## التشغيل

يتطلب المشروع Node.js وpnpm. من مجلد المشروع شغّل:

```bash
pnpm install
pnpm dev
```

لفحص الأنواع وإنشاء نسخة الإنتاج:

```bash
pnpm typecheck
pnpm build
```

## بدء اللعب والحفظ

عند أول فتح، اختر الدولة واكتب اسم المستثمر ثم ابدأ العالم. مصر هي الدولة الوحيدة المضافة في هذه المرحلة، ورصيدها الابتدائي مليون جنيه مصري. يحفظ التطبيق ملف اللاعب في `localStorage` ويستعيده تلقائيًا في الزيارات التالية. من الإعدادات يمكن بدء عالم جديد؛ لن يُمسح الحفظ إلا بعد تأكيد صريح.

بعد أول زيارة متصلة، يسجل إصدار الإنتاج عامل خدمة ويحفظ غلاف التطبيق محليًا لتيسير فتحه دون اتصال. تستخدم النسخة الحالية صورة القاهرة الموجودة في `public/images` محليًا؛ الصورة من صفحة Unsplash العامة: https://unsplash.com/photos/city-skyline-with-river-and-boats-under-hazy-sky-Z1tl3nb_c4E . راجع https://unsplash.com/license .

## تجهيز Android لاحقًا

يوجد `capacitor.config.ts` وحزما Capacitor الأساسية وAndroid. بعد توفير بيئة تطوير Android المناسبة، أضف مشروع Android مرة واحدة عبر:

```bash
pnpm cap:add:android
```

ثم حدّث ملفات الويب الأصلية إلى المشروع عبر:

```bash
pnpm cap:sync
```

إنشاء حزمة Android وتوقيعها ونشرها غير منفذ في هذه المرحلة.
