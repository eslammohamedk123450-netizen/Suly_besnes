# الحسابات وأكواد المكافآت

## الحساب المحلي

يبدأ التطبيق بشاشة تسجيل دخول أو إنشاء حساب بالبريد الإلكتروني وكلمة المرور. لا توجد رسائل تحقق أو أكواد دخول. الحسابات تحفظ محليًا على الجهاز، ويُفصل ملف تقدم كل حساب بمعرفه الخاص. لذلك لا توفر هذه النسخة مزامنة بين الأجهزة أو استعادة كلمة المرور بعد حذف بيانات التطبيق.

## توليد كود مكافأة

الأكواد منفصلة تمامًا عن تسجيل الدخول. لتوليد كود محليًا:

```bash
pnpm code:issue -- --cash 50000 --gold 0.5 --expires 2027-12-31T23:59:59Z
```

الأداة تنشئ مفتاح Ed25519 محليًا داخل `.local/` عند أول تشغيل، وتطبع كودًا بصيغة `SULY1`. المفتاح الخاص لا يدخل Git ولا APK. داخل اللعبة توجد شاشة استرداد في الإعدادات تتحقق من التوقيع والصلاحية وتمنع استخدام معرف الكود مرتين على نفس الحساب، ثم تضيف المكافأة وتسجلها في الدفتر كمعاملة واحدة.

## حدود مهمة

الحساب المحلي ليس نظام حساب سحابيًا. من يريد الدخول من عدة أجهزة أو استعادة كلمة المرور يحتاج خدمة خلفية ومزامنة لاحقة. كذلك لا يمكن ضمان استخدام الكود مرة واحدة عالميًا دون سجل مركزي؛ الحماية المحلية تمنع التكرار داخل ملف الحفظ المحلي فقط.
